# FoxLED Experiments & Historical Archives

This folder holds historical prototypes and auxiliary builds created during the evolution of FoxLED:

- **[`python-prototype/`](python-prototype/)**: The initial Python 3.7 / PyQt5 prototype for serial WS2812B LED control, screen ambilight capture, and early audio reactivity (2018).
- **[`client-bin/`](client-bin/)**: Compiled standalone FoxLED Windows client with NAudio integration for audio reactivity and sound spectrum analysis.
