# FoxLED Experiments & Prototypes

This directory contains complementary services and client prototypes built during the FoxLED development cycle:

- **`foxled-server/`**: Windows background network server built with C#, WPF, FluentWPF, and Socket.io to relay ambient color signals across multiple local machines and microcontrollers over TCP/IP.
- **`foxled-wpf-client/`**: Early compiled WPF visualizer and audio frequency analyzer utilizing `NAudio` and `Newtonsoft.Json`.
