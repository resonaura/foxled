# FoxLED — Python Prototype

[![Language](https://img.shields.io/badge/Language-Python%203.7-3776AB.svg?logo=python&logoColor=white)](#overview)
[![Framework](https://img.shields.io/badge/Framework-PyQt5%20%7C%20PyAudio-41CD52.svg)](#overview)

This directory contains the initial **Python prototype** for FoxLED created in 2018 before the project was rewritten in C# / WPF.

### 📜 Overview & Features
- **`easyled.py`**: Serial communication library transmitting RGB frame buffers across COM ports.
- **`easyaudio.py`**: Fast low-latency audio stream processing and frequency filtering.
- **`gui.pyw`**: Early desktop GUI panel created with PyQt.
- **`anim.py`**: LED animation patterns, color-music visualization modes, and color palettes.
- **`old/`**: Historical experimental scripts exploring screen ambient backlighting (ambilight), system telemetry (CPU load and core temperature), and custom color effects.
